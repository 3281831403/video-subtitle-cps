# 视频字幕阅读速度 CPS 修复

## 题面

字幕上线前做阅读速度检查后，长句还是来不及读、短句又重叠：字符数把空格也算，CPS 偏高；CJK 标点按 1 字计，实际阅读更慢；CPS 用分钟而不是秒，数值差 60 倍；拆分按等分时间而不是按字符，长句来不及读；合并不更新起止，出现重叠；补时长把前一条延长，压住后一条；均衡拆分行首放标点，观感差；重叠不报错，播放器随机选一条；批量共用字幕列表，轨之间串；max_cps<=0 不校验，除零。cps/reading.py 是核心，tests/test_reading.py 15个红。要修的是：按上述 10 个缺陷逐项实现 `cps/reading.py` 的 8 个函数，并保持 15 条测试全部通过。

## 运行方式

在仓库根目录执行：

```powershell
python -m pytest tests -q
```

初始失败环境应当恰好输出：

```text
15 failed
```

这 15 条测试都会调用 `cps/reading.py` 中的未实现桩，因此是正常的 `failed`，不是 collection/import/syntax error。不要通过修改测试来消除失败。
